Agent events → control plane → operator

Agents never touch a system directly. Every tool call is a request to the control plane, and every request, verdict and intervention is an event.

{% endblock %} {% block body %}

1 · Agents

  • 4 asyncio workers, 3 jobs: KYC, withdrawals, support
  • Reason with free LLMs: Groq gpt-oss-20b → Gemini Flash-Lite → OpenRouter, scripted fallback
  • Checkpoint between every step: pause / kill land within one step

2 · Tool gateway

  • Only path from an agent to a system
  • Credentials check (revoked → refuse)
  • Policy verdict: allow · approve · deny
  • Approval = a future the agent awaits

3 · Control plane

  • Policy engine (policy.yaml): scope, egress, PII, privilege, budget, limits
  • Guardian: strikes, rate, drift → quarantine
  • Prompt Guard input scan → taint
  • Event store: SQLite, SHA-256 chained

4 · Operator UI

  • SSE stream → HTMX panels (no polling)
  • Approve / deny, pause / resume, kill / restart, release
  • Replay last N steps, cost per task
  • Tenant filter, audit export + verify

Life of a risky action

  1. Faisal (withdrawals) decides to pay 18,500 BHD to a beneficiary added 2 hours ago and calls payments.execute.
  2. The gateway asks the policy engine: amount above the tenant's 2,000 BHD threshold and a new beneficiary, so the verdict is approve at risk 75.
  3. An approval is queued and approval.requested is emitted; the SSE stream pushes it to every operator screen within a second.
  4. Faisal's card turns amber: Awaiting human approval. The agent is parked on a future; nothing executes.
  5. The operator opens the replay to see why, then approves or denies. The decision, the operator's name and the wait time are chained into the audit log. No decision within 10 minutes means it expires: fail closed.

Multi-tenant

Every event carries a tenant_id. Policy thresholds, currencies and egress rules are per tenant. The tenant switcher scopes the fleet, the queue, the stream, costs and the audit export. An emergency stop can be fleet-wide or per tenant.

Tenants mirror sectors DOO serves (banking, telecom, delivery) and are fictional.
