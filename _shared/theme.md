# Theme - Navy

Taken from navy-astro.pages.dev with Firecrawl (branding + screenshot). Implemented in `app/static/tower.css`.

- Type: Switzer (Fontshare), 400/500/600/700. Big light headlines with one bold-italic word.
- Ink `#111428`, secondary `#585D6F`, background `#FAFBFF`, soft `#EAEEFC`, button `#DBDFFF`.
- Hero: deep navy `#03051A` fading through blue `#1E34B8` to lavender and the page background.
- Square corners everywhere, hairline borders, no shadows.
- Status colours (added for operations): ok green, warn amber, critical red, each with a pale fill.
